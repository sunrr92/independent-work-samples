ASTER - ORIGINAL CHAT INTERFACE CONCEPT

New, original concept work created for this demonstration. This is not past client work.
All conversation text, the Aster identity and the abstract SVG artwork are fictional.

Open dist/index.html directly in a browser. No build, installation, account, server,
external font, image download, API, subscription or other purchase is required.

Working local interactions:
- Type a message and press Enter or Send. Shift+Enter adds a new line.
- Three prompt chips fill the composer. Replies are explicitly labelled scripted demos.
- Switch Midnight / Quiet tide / First light to change color, illustration and scene copy.
- Start a new conversation to reset the sample and clear entered messages.
- Mark/unmark the reminder for this session, and open the concept information dialog.
- On narrow screens, Atmosphere opens an accessible drawer with Escape/Tab handling.

Messages and reminder state are held in memory only. Reload clears them. No messages
are sent or saved. There is no AI backend, authentication, analytics or live support.
Animations respect prefers-reduced-motion. Controls support keyboard navigation.

Source: one self-contained HTML file with CSS, JavaScript and original inline SVG.
This folder contains only the current page and this short description. No deployment
or Sites registration has been performed. Browser/device acceptance is a separate check.
